# 🌻 植物大战僵尸 3D 写实版 (Plants vs Zombies 3D Realistic)

基于现代 **Three.js** 与 **Vite** 构建的全 3D 高清写实风格双端跨平台《植物大战僵尸》。电脑与手机打开浏览器直接玩，免安装任何客户端！

---

## 🌟 核心特色

### 1. 📱 双端自适应体验（电脑 + 手机完美适配）
* **响应式双端视角**：
  * **电脑宽屏 / 手机横屏**：经典大视野 3D 庭院全景。
  * **手机竖屏**：智能自适应为纵向长轴透视推进视角，完美符合手机单手单指操作习惯。
* **触控与快捷键**：
  * 移动端支持触控拖拽/点击种植、滑过磁吸拾取阳光。
  * 电脑端支持鼠标滚轮缩放、右键拖拽微调 3D 视角，键盘数字键 `1-7` 选卡，`S` 键铲子，`C` 键切换视角，`N` 键日夜切换。

### 2. 🎨 极致画质与逼真人物（PBR 物理渲染）
* **写实丧尸军团**：
  * 真实人体解剖学比例与腐坏肌理、破旧西装与牛仔裤、下垂下颚与发光眼眸。
  * 骨骼层级步态动画（瘸腿摇晃行进、撕咬动作、受击头部/残肢飞溅与倒地衰减）。
  * 真实护甲脱落机制（路障击碎击飞、铁桶金属反光与中弹火花）。
* **拟真植物设计**：
  * **向日葵**：逼真葵花盘与双层金黄花瓣，呼吸律动光晕。
  * **豌豆射手**：有机叶脉质感与后坐力回弹发射。
  * **寒冰射手**：晶莹剔透冰晶质感与寒霜减速射线。
  * **坚果墙**：写实坚果褶皱硬壳与 3 阶段真实破裂破损。
  * **土豆地雷**：地表泥土破土就绪与天线闪烁引信。
  * **大嘴花**：上下颌骨联动尖牙、近战一口吞咽与真实消化律动。
  * **樱桃炸弹**：光泽感孪生樱桃、引信燃烧火花与全屏震颤爆破。
* **电影级后处理与特效**：
  * 动态柔和实时阴影（PCFSoftShadow）、晨昏光照与日夜切换（☀️ 白天阳光草坪 / 🌙 夜间墓地迷雾）。
  * 屏幕震颤系统（爆炸剧烈震屏）、绿汁碎肉粒子、金属火花、泥土飞溅。
  * 内置**画质切换面板**（高 / 中 / 低），适配不同性能设备满帧 60 FPS 运行。

### 3. 🧟 丰富阵容与关卡机制
* **7 种植物**：向日葵、豌豆射手、寒冰射手、坚果墙、土豆地雷、大嘴花、樱桃炸弹。
* **6 种丧尸**：普通丧尸、路障丧尸、铁桶丧尸、撑杆跳丧尸（撑杆跃过防线）、摇旗丧尸、巨型丧尸 Gargantuar（体型巨大、手持电线杆重击）。
* **完整防线机制**：每行配备 3D 除草机保底防线、大波尸潮警报、决战波次。
* **沉浸式音效**：基于 Web Audio API 原生合成音效（中弹、金属撞击、咀嚼啃食、爆炸轰鸣、丧尸咆哮）。

## 🚀 启动与体验方法

### 本地启动
```bash
# 安装依赖（已预装）
npm install

# 启动开发服务器（支持电脑和局域网手机访问）
npm run dev
```

启动后控制台会显示：
* 本地访问：`http://localhost:3000/`
* 同局域网手机访问：`http://<局域网IP>:3000/`（手机与电脑连接同一 Wi-Fi 时，用手机浏览器打开该 IP 地址即可直接畅玩）

### 生产打包
```bash
npm run build
```
编译产物位于 `dist/` 目录，可直接部署至任何静态托管平台（GitHub Pages、Vercel、Nginx、Cloudflare 等）。
